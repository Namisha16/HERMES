# HERMÈS GOOGLE AI STUDIO WEBSITE PACKAGE

START HERE:
1. Read 01_DESIGN_GUIDELINES.md
2. Read 00_MASTER_DATASET.json
3. Read 03_ASSET_MANIFEST.json
4. Read 04_DATA_SOURCES.json
5. Put verified/licensed assets into ASSETS/ and update the manifest with filenames and rights.
6. Start Google AI Studio with 01_STARTER_PROMPT.txt.
7. Then run 02_BUILD_PROMPT.txt.
8. Refine with 03_REFINEMENT_PROMPT.txt.
9. Audit content with 04_CONTENT_AUDIT_PROMPT.txt.
10. Finish with 05_FINAL_QA_PROMPT.txt.

The included hermes images.xlsx is the user's asset/reference spreadsheet. Reconcile its image/source rows into the asset manifest during implementation.

The website architecture is intentionally data-driven: the common landing page supports Hermès plus future houses. Hermès is the first complete brand world.

Do not invent research, historical imagery, dates, prices or quantitative values.
Historical images should be verified and rights-cleared for the intended use.
